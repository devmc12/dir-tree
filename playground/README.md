# Dir Tree Playground

A browser demo for loading folders and ZIP archives, editing trees and annotations, configuring ASCII output, and exporting TXT, Markdown, or JSON. Available in English and Chinese.

## Run

From the repository root:

```bash
npm install
npm --prefix playground install
npm run dev:playground
```

## Checks

```bash
npm --prefix playground run typecheck
npm run build:playground
```

See the [Playground guide](../docs/playground.md) for features and source locations.
